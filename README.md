# Hybrid Coach

App web para móvil para entrenar fondo y fuerza día a día, con el plan del entrenador ordenado hacia una carrera objetivo.

- **Hoy**: el entreno del día, los ritmos, la fuerza y la cuenta atrás para la carrera.
- **Semana**: puedes elegir tu día de descanso y pasar a una semana suave si no estás a tope.
- **Plan**: las semanas hasta la carrera, agrupadas por fases.
- **Fuerza**: los circuitos PFG, Circuito training, PFG IV y Fuerza y vallas.
- **Historial**: tus entrenos y los km por semana.

Los datos de cada persona se guardan en su propio móvil. Desde «Mi objetivo» se puede descargar una copia de seguridad.

Para tenerla como app: ábrela en Chrome y en el menú ⋮ elige «Añadir a pantalla de inicio».
